# โหมด AUTO — ตรวจ "องค์ประกอบหาย" อัตโนมัติ

## ต่างจากโหมด ROI เดิมอย่างไร
โหมด ROI เดิมต้องลากกรอบเองทีละจุด ตรวจได้เฉพาะที่ลาก
**โหมด AUTO แยกชิ้นส่วนจาก Master เองทั้งภาพ** แล้วตรวจทุกชิ้น ไม่มีตกหล่น

## กลไก 5 ขั้น

### ขั้น 1 — แยกชิ้นส่วน (`segment_elements`)
ใช้ connected components บน ink mask ของ Master
→ ได้ตัวอักษรแต่ละตัว, วงกลม E6/TIS, เส้นขีดบน SNI, โลโก้ แยกเป็นคนละชิ้น
`merge_gap` > 0 จะรวมชิ้นที่อยู่ติดกันเข้าเป็นก้อนเดียว (เช่นอยากให้ `SNI` เป็นก้อนเดียว ตั้ง 6–10)

### ขั้น 2 — จำแนกชนิด (`classify`)
| ชนิด | เงื่อนไข | เกณฑ์ตัดสิน |
|---|---|---|
| `LINE` | ยาว/บาง (aspect ≥ 3.5 และหนา ≤ 30% ของความสูงเฉลี่ย) | เข้มกว่า (`miss_half_line` 0.80) |
| `RING` | bbox เกือบจัตุรัส + ใหญ่กว่าตัวอักษรทั่วไป ≥ 1.6 เท่า + พิกเซลหมึกเรียงเป็นวงแหวน (std รัศมี/ค่าเฉลี่ย < 0.22) | เข้มกว่า |
| `TEXT` | นอกเหนือจากนั้น | `miss_half` 0.70 |

เงื่อนไข "ใหญ่กว่าตัวอักษรทั่วไป" คือสิ่งที่กันไม่ให้ตัวอักษร `O` `C` `G` ถูกเข้าใจผิดว่าเป็นวงกลม

### ขั้น 3 — วัด coverage (`measure`)
```
coverage = หมึกที่ยังอยู่ ÷ หมึกใน Master
```
แล้วแยกวัดเป็น 4 ทิศเพิ่ม:
- `cov_L` / `cov_R` — ครึ่งซ้าย / ครึ่งขวา (**แกน X**)
- `cov_T` / `cov_B` — ครึ่งบน / ครึ่งล่าง (**แกน Y**)

นี่คือส่วนที่ตอบโจทย์ "หายครึ่งหนึ่งทั้งในด้าน X และ Y"

### ขั้น 4 — ตัดสิน (`judge`)
| coverage | ผล |
|---|---|
| < `miss_full` (0.25) | **MISSING** — หายทั้งชิ้น |
| < `miss_half` (0.70) | **PARTIAL** — หายบางส่วน |
| ครบ แต่ครึ่งใดครึ่งหนึ่ง < `half_side` (0.45) | **PARTIAL** + ระบุทิศ เช่น "หายด้าน ซ้าย 0%" |
| นอกนั้น | OK |

### ขั้น 5 — IGNORE ZONE
กรอบที่ลากเป็น `ignore` (เช่นเลข 2 4 6 8 ด้านล่าง) จะ:
- ข้ามชิ้นส่วนที่จุดศูนย์กลางตกในกรอบ → ไม่ฟ้อง MISSING
- ล้างพื้นที่นั้นก่อนหา EXTRA → เลขเปลี่ยนเป็นอะไรก็ไม่ฟ้อง

## ใช้งานผ่าน UI

1. ดับเบิลคลิก `RUN_UI.bat`
2. เลือก **Master** และ **Test**
3. แท็บ **1. กำหนดกรอบบน Master** → เลือก "โซนไม่ต้องตรวจ (IGNORE)" → ลากคลุมแถวเลข 2 4 6 8 → ตั้งชื่อ `DOT_2468`
4. กด **บันทึก** เก็บเป็น `config.json` (ครั้งต่อไปกด **โหลด** ได้เลย)
5. โหมดเลือก **AUTO** → กด **▶ ตรวจสอบ**
6. แท็บ 2 ดูภาพ, แท็บ 3 ดูตารางรายชิ้น (กรอง "เฉพาะที่ผิดปกติ")

สีกรอบ: 🟩 OK | 🟧 หายบางส่วน | 🟥 หายทั้งชิ้น | 🟪 หมึกเกิน | ⬜ โซนไม่ตรวจ

## ใช้งานผ่านคำสั่ง
```
python glyph_check.py --master m.png --test t.png --ignore config.json --out res
```

## การจูน

| อาการ | แก้ที่ |
|---|---|
| ฟ้อง PARTIAL เต็มไปหมดทั้งที่ของดี | เพิ่ม **Tolerance px** 2→3–4, ลด **หายบางส่วน** 0.70→0.55 |
| ตัวอักษรแตกเป็นหลายชิ้น | เพิ่ม **รวมชิ้นติดกัน px** เป็น 4–8 |
| จุด noise เล็ก ๆ ถูกนับเป็นชิ้นส่วน | เพิ่ม **ชิ้นเล็กสุด px²** 40→80 |
| หายครึ่งตัวแล้วยังไม่ฟ้อง | เพิ่ม **หายครึ่งด้าน** 0.45→0.60 |
| เส้นขีดบางหลุด | เพิ่ม **เส้น/วงกลม** 0.80→0.90 |

**ลำดับจูนที่แนะนำ:** รันกับใบ OK จริง 30 ใบก่อน ปรับจนไม่มี false NG → แล้วค่อยรันใบ NG ต้องจับได้ครบ 100%
